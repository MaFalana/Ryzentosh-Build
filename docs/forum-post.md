# Forum Post — B850 EXITBS Triple-Fault

Post to: r/hackintosh, forum.amd-osx.com, AMD OS X Discord

---

**Title:** B850 + Ryzen 9 7950X — Kernel triple-fault at EXITBS:START (tried everything)

**Body:**

Hardware:
- ASUS ROG STRIX B850-A Gaming WiFi
- AMD Ryzen 9 7950X (Zen 4)
- AMD Radeon RX 6600 (Navi 23, 0x73FF)
- 2x32GB DDR5 5600MHz (Micron)
- BIOS: v1686 (AGESA ComboAM5 PI 1.3.0.1b Patch A)
- OpenCore 1.0.8

Trying to boot macOS Sequoia 15.7.9 installer from USB. Boot.efi loads fine, kernel collection loads (~800ms), EXITBS:START is reached — then instant reboot. No verbose output after EXITBS. `debug=0x144` doesn't halt (triple-fault, not kernel panic).

Tested both Sequoia and Monterey — same result. Also tried a completely fresh config generated by OCSimplify.

**What I've tried:**
- ProvideCurrentCpuInfo on/off
- SMBIOS: iMacPro1,1 and MacPro7,1
- SetupVirtualMap true/false
- DevirtualiseMmio true/false
- ProtectUefiServices true/false
- DisableVariableWrite true/false
- WhateverGreen enabled/disabled
- PAT patches: algrey, Shaneee, both disabled + mtrr_update_action=0
- IOPCIIsHotplugPort on/off
- npci=0x2000, slide=0
- CSM disabled, Resize BAR enabled/disabled
- Disabled WiFi + Ethernet in BIOS
- Different USB ports (chipset + CPU-direct)
- BIOS update from v0806 (AGESA 1.2.0.2) to v1686 (AGESA 1.3.0.1b)
- Fresh OCSimplify-generated EFI
- DebugEnhancer.kext (no output — crash is pre-kext)
- Followed fabiosun's B850 fix from forum.amd-osx.com (no WEG, ResizeBAR, DisableVariableWrite)

**Boot log (typical):**
```
[EB|MBA:NV] <"-v debug=0x100 keepsyms=1 npci=0x2000 slide=190">
[EB.LD.LKC|R.2] <"System\Library\KernelCollections\BootKernelExtensions.kc">
[EB.LD.LKFS|-?] Ok(0)
[EB.LD.LKC|-?] Ok(0)
[EB|LOG:EXITBS:START] 2026-08-25T08:15:48
```

Has anyone gotten macOS working on an ASUS ROG B850 board? The MSI B850 fix (fabiosun's thread) didn't work for me. Wondering if this is an ASUS-specific firmware issue.
